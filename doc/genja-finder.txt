1. Usage                                               *genja-finder-usage*

`require('genja-finder').live_grep(opts)`             *genja-finder.live_grep()*
    Text search. Backends: rg, ack, GNU grep (first found in PATH).
    Prompt: `pattern  -g *.lua`. Two spaces split the pattern from extra
    flags, which go to the backend as typed.

`require('genja-finder').live_find(opts)`             *genja-finder.live_find()*
    Files by name. Backends, first found and ready: es, locate, fd, fdfind,
    rg --files. es (Everything) and locate query their index on each
    keystroke, from `min_chars` on, at most `max_results` paths; es is
    skipped when Everything isn't running and takes Everything's search
    syntax (`ext:lua`). fd and rg list once and fuzzy match.

`require('genja-finder').setup(opts)`                 *genja-finder.setup()*
    Merge {opts} into the defaults. Optional.

`require('genja-finder').attach_shared_keys(map)`
                                            *genja-finder.attach_shared_keys()*
    For any picker's attach_mappings: Telemap keys (<esc> close, <F2>/<F3>
    next/previous), <M-f> filter, <M-x> exclude, <BS> undo and <M-n> exact match.

`require('genja-finder').enhance(picker)`             *genja-finder.enhance()*
    Wrap a picker function so it opens with the keys of
    |genja-finder.attach_shared_keys()|: >lua
    require('genja-finder').enhance(require('telescope.builtin').oldfiles)()
<   Sets `opts.attach_mappings`; telescope runs it after the picker's own.
    A picker that doesn't pass its opts to pickers.new gets nothing.

`require('genja-finder.refine').decorate(picker, attach)`
                                                *genja-finder.decorate()*
    Like |genja-finder.enhance()| with your own `attach(map)`; default:
    <M-f> only (`require('genja-finder.refine').attach`).

`require('genja-finder.telemap').Telemap(map)`        *genja-finder.Telemap()*
    Telemap keys only.

2. Keys                                                *genja-finder-keys*

    <M-r>   cycle root: pwd, …/.git, bufdir, home (and arg, first, when a
            cwd was passed)
    <M-Up>  one-off: rescan in the parent of the scanned dir; the root and
            the <M-r> cycle stay, <M-r> goes on from the root
    <M-i>   cycle skip set: gitignore+, vend+mods+dist, unrestricted
    <F1>    switch live grep <-> live find, keeping root (or cwd), skip and text
    <M-c>   popup with the command being run; `y` copies it, <M-c> closes
    <M-C>   reopen with the next command in `binary`, skipping missing or
            not ready ones; wraps around
    <C-p>   toggle the preview (off by default)
    <M-f>   filter: fuzzy-match within the listed results on a fresh prompt;
            again narrows further. <M-r> <M-i> <F1> <M-c> keep the search
    <M-x>   exclude: drop the listed entries that contain any typed word
            (smartcase) on a fresh prompt, prefix `!word > `. Needs a fixed
            list: live grep/find only after <M-f>
    <BS>    on an empty prompt: undo the last <M-f> or <M-x>, back to its results
            and text; otherwise deletes a character
    <M-n>   switch between fuzzy and exact match: every word must appear
            as typed (smartcase). New <M-f> steps start in the current
            mode; <BS> undo restores the earlier step's mode. Live grep:
            only after <M-f> (rg matches the pattern before that)
    <M-F>   live find only: popup for a file name part; lists only files
            whose name contains it (case-insensitive, `*.ahk` is a glob)
    <M-g>   live grep only: cycle a file filter

3. Options                                             *genja-finder-options*

Shared (|genja-finder.setup()| top level, or per call):

    root           'pwd'|'git'|'bufdir'|'home'        default 'pwd'
    cwd            directory to scan; shown as root 'arg' and kept in the
                   <M-r> cycle
    ignore         'gitignore+'|'vend+mods+dist'|'unrestricted'
    exclude        dir names skipped (node_modules, vendor, dist)
    exclude_files  file globs skipped (*.min.js, *.min.css)
    hidden         include dotfiles                   default true
    ivy            ivy bottom pane layout             default true
    show_preview   preview visible at open            default false
    attach         fun(map): extra picker keys
    file_ignore_patterns
                   telescope's own filter, see below  default: global

Both pickers heed telescope's global `file_ignore_patterns` (Lua patterns,
matched anywhere in the path). They drop files after the backend ran, in every
skip mode including unrestricted, and the <M-c> command does not show them.
Unanchored patterns hide more than meant: `"%.a"` also drops `x.ahk`; write
`"%.a$"`. Override for the finder only, <F1> passes it to the other picker: >lua
    require('genja-finder').setup { file_ignore_patterns = {} } -- {} = none
<
`grep = {...}`: binary, backend, extra_args, separator, min_chars, filters.
`find = {...}`: binary, backend, follow, min_chars (2), max_results (15000).
